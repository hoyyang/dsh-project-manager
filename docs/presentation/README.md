# Project board — Russian presentation

`dsh-project-board-ru.html` is a standalone HTML slide deck about the **Проектная доска** (project board) and the Russian localization work for `dsh-project-manager`. Open it in any browser.

- It is a single self-contained file; styles and fonts are loaded from a CDN (Tailwind CSS, Google Fonts), so it needs internet access to render fully.
- Screenshots inserted in the deck show the board UI after localization.
- The deck is written in Russian; the implementation notes in `i18n/README.md` are in English.

If you prefer not to keep a presentation in the repository, this directory can be dropped without affecting the localization itself.
